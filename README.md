# Bug bounty notes — public index and methodology

This repository is the **public-safe** part of my bug-bounty notes. It lists public
programs and the generic methodology I use. It does **not** contain finding details,
proofs of concept, evidence, target-specific paths, or unpublished vulnerability
information.

Finding summaries are added here only after the program discloses the report or gives
written permission. Until then they stay in a private archive.

## Contents

- [PUBLIC-PROGRAMS.md](PUBLIC-PROGRAMS.md) — index of public HackerOne programs
- [METHODOLOGY.md](METHODOLOGY.md) — generic, non-operational method notes
- [SANITIZATION.md](SANITIZATION.md) — what is and is not allowed in this repository

## Ethics

All testing referenced here was performed inside the published scope of the named
program, under its rules, with researcher-owned accounts. No customer data is included.
Program names and trademarks belong to their owners; this repository is not affiliated
with or endorsed by any program.
